# AI-Powered Portfolio Assistant | Day 29 Project

This is my personal portfolio website enhanced with an **AI-powered Q&A assistant**. Visitors can ask questions about my **resume, skills, projects, and internships**, and get instant, interactive answers directly on the website.

## Features
- **Interactive Q&A Bot:** Answer questions related to my resume and projects
- **Instant Responses:** Keyword-based AI logic using JavaScript
- **Responsive Design:** Works on desktop and mobile
- **Animated UI:** Typed.js animations for dynamic effects
- **Portfolio Sections:** Home, Career, Blog, Work Experience, Projects, Skills, Contact

## Tech Stack
- **HTML5 & CSS3**
- **JavaScript (ES6)**
- **Typed.js** for animated text
- Simple JSON-based AI assistant logic (local)

## What I Learned
- Implementing a local AI assistant using JavaScript
- Integrating interactive Q&A functionality into a portfolio website
- Enhancing user experience with animations and responsive design
- Making a portfolio **more engaging and interactive** for recruiters

## Future Improvements
- Upgrade to GPT-powered AI for dynamic, intelligent responses
- Store Q&A history for user convenience
- Enhance mobile and UI interactivity
